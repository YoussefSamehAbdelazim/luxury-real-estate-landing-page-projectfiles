# Luxury Real Estate Website

A modern and responsive Arabic real estate website designed to showcase residential and commercial properties with an elegant user experience.

## Overview

Luxury Real Estate is a front-end website for a real estate company, built with a modern layout and a fully Arabic right-to-left (RTL) interface. It provides visitors with an organized way to explore available properties, learn about the company's services, read customer testimonials, and get in touch through the contact section.

## Features

- Modern and elegant real estate website design.
- Fully Arabic interface with RTL layout support.
- Responsive design for desktop, tablet, and mobile screens.
- Property listings with category filtering.
- Interactive property favorites toggle.
- Testimonials slider with autoplay and touch support.
- Contact form with input validation.
- Interactive navigation and smooth scrolling experience.
- Animated statistics counters.
- Scroll reveal animations.

## Website Sections

| Section | Description |
|---|---|
| Home | Hero section introducing the real estate company. |
| About | Information about the company. |
| Properties | Property listings with category filters. |
| Services | Overview of the real estate services. |
| Testimonials | Customer reviews displayed in an interactive slider. |
